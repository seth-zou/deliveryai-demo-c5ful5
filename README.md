# 沸点火锅点单演示

一个面向火锅门店场景的移动端点单与履约流程演示项目，用于展示从绑定餐桌、多人点餐到订单履约和结账支付的完整体验。

> 本项目为概念演示，不代表正式产品。

## 功能介绍

- 绑定餐桌并进入点餐流程
- 按分类浏览、搜索和选择菜品
- 配置菜品规格、口味及下单人
- 多人协同点餐与购物车管理
- 查看订单制作及上菜进度
- 呼叫加汤、饮料、餐具和结账服务
- 模拟菜品售罄、服务响应及履约状态
- 模拟结账和支付成功流程
- 支持中英文切换、老人模式与儿童模式

## 技术栈

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Radix UI
- i18next
- Playwright

## 环境要求

- Node.js 18 或更高版本
- npm 9 或更高版本

## 本地开发

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

服务默认运行在 `http://localhost:5173`。如果该端口已被占用，Vite 会自动选择其他可用端口。

## 常用命令

```bash
# 启动开发服务
npm run dev

# 执行代码检查
npm run lint

# 构建生产版本
npm run build
```

生产构建产物会生成在 `dist/` 目录。

## 预览模式

访问以下地址可以直接进入已绑定餐桌并带有购物车数据的菜单预览：

```text
http://localhost:5173/?preview=menu
```

儿童模式预览（含受限菜单、状态横幅与家长退出流程）：

```text
http://localhost:5173/?preview=child-mode
```

预览模式固定使用家长密码 `1234`，便于验证退出流程；正式使用时由家长在开启时自行设置。预览只作用于当前页面内存态，不会写入或覆盖真实设备上的儿童模式开关与家长密码摘要。

## 儿童模式（演示级）

- 入口：首页、欢迎页胶囊按钮与店内顶栏图标；开启后顶栏下方常驻琥珀色状态横幅与「家长退出」（滚动时随顶栏一起吸顶）。
- 受限范围：重辣 / 超级辣 / 香辣腌制口味，在线支付与结账页、买单、退菜、会员与排队、多人协同、演示控制台；保留浏览、搜索、加购、提交订单、加菜、加汤 / 饮料 / 餐具与语言切换。
- 退出：需输入开启时设置的 4 位家长密码；错误密码保持儿童模式。忘记密码请联系门店工作人员。
- 存储：`localStorage` 的 `child-mode`（`true`/`false`）与 `child-mode-pin-hash`（演示用摘要，非明文）；状态按设备记忆，不跨设备同步。
- 异常恢复：若检测到「开关为开启但密码摘要缺失」，自动清理异常状态并提示恢复为常规模式（会话级一次性提示），避免用户被永久锁死。
- 安全边界：本地 4 位 PIN 仅用于演示级防误触，**不是真实安全能力**；正式上线需服务端家长验证、密码找回与失败锁定。

E2E 针对儿童模式覆盖开启 / 退出、受限口味、支付与买单拦截、刷新保持、跨标签页同步、`localStorage` 不可用降级、异常自动恢复、老人模式叠加、已支付不误拦与预览隔离；其中「`localStorage` 不可用」用例运行在生产构建（`vite preview`，默认端口 4399），由 `playwright.config.ts` 的 `webServer` 自动执行 `npm run build` 后启动。

实际端口以 Vite 启动日志为准。
